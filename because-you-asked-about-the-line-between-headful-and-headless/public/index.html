Both pages carry a magenta sweep bar and a millisecond clock. Compare the two panes to read off the end-to-end lag of each transport. Screencast frames are pulled straight from Kernel by this tab — the cdp_ws_url JWT authenticates the WebSocket, so no frames pass through the local Node process. Note that screencast captures the page viewport only, while live view shows the whole desktop including browser chrome.

Both panes are interactive. Pane A is Kernel's built-in interactive live view; pane B forwards mouse and keyboard events from the canvas into the browser via Input.dispatchMouseEvent / Input.dispatchKeyEvent. Click the canvas first so it takes keyboard focus. Uncheck forward input to make pane B read-only.
